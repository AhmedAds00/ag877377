# Series templates

Recurring formats make a creator's content recognizable. Use one of these only when the creator asks for a series, or when a topic fits one naturally. Do not force a template onto a topic that works better with a different angle.

## 1. Tool in one minute

- **Shape:** what the tool does, one real demonstration, one practical tip, CTA.
- **Length:** 30 to 45 seconds.
- **Hook pattern:** a specific problem the tool solves, shown on screen in the first two seconds.

## 2. Mistake and fix

- **Shape:** the common mistake people make, why it happens, the fix shown step by step.
- **Length:** 40 to 60 seconds.
- **Hook pattern:** "أغلب الناس يسوون كذا، والصح هو..." followed by the result of the fix.

## 3. Hidden feature

- **Shape:** where the feature is, how to turn it on, what it changes in daily use.
- **Length:** 30 to 45 seconds.
- **Hook pattern:** a demonstration of the result before explaining the path.

## 4. Before and after

- **Shape:** the same task done the old way, then with the tool or feature, showing the time or effort difference.
- **Length:** 30 to 50 seconds.
- **Hook pattern:** the "after" result shown first, then "this is how".

## 5. Myth vs reality

- **Shape:** a common belief, what is actually true, the evidence or demonstration.
- **Length:** 40 to 60 seconds.
- **Hook pattern:** the myth stated in one line, then the correction.

## Using a series

- Keep the same structure and intro line style across episodes so viewers recognize the format.
- Number episodes in the on-screen text when the creator wants it, for example "الحلقة 3".
- Reference the log before choosing a topic, so episodes do not repeat.
